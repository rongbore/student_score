# 星光课堂 · 学生积分管理

明亮卡通风格的班级管理应用。支持四个教学班、学员资料、课堂与课后积分、并列排名、积分记录及编程课程整理。无需后端和依赖安装。

## 运行

直接打开 `index.html`，或在仓库目录运行：

```sh
python3 -m http.server 3000
```

浏览器访问 `http://localhost:3000`。初始为四个空班级；已有数据会从当前浏览器读取。

## 日常使用

- **学员资料**：添加或编辑姓名、文本格式年级、学习账号、手机号及闪光点；学习账号不区分大小写查重，支持按姓名、账号或年级搜索。手机号只在编辑资料时显示。
- **积分操作**：单人或勾选多名学生批量加减分；每人每次为 1–1000 整数分。课后积分包含在总积分中，允许负分。同分学生并列排名，140 分及以上可筛选为积分小明星。
- **误操作撤销**：进入「积分记录」撤销新操作；批量记录按整个批次撤销，保留原记录并标注「已撤销」。旧版记录缺少学生编号，仍可查看，但不提供自动撤销。
- **课程整理**：12 次课程各包含知识点总结、随堂练习、课后练习。教师整理的内容供所有班级使用，授课进度按班级保存。原课程网站正文尚未导入，不会将教师整理内容标为原站内容。
- **班级管理**：新建及重命名班级，禁止空名称与同名班级。

## 备份与恢复

右上角「备份」导出 `classbloom-backup-v1` JSON，包含全部班级、学员资料、积分记录、课程内容和各班授课进度。「恢复」选择文件后会先展示班级、学员和记录数量；确认时下载当前数据备份，再替换为导入的数据。取消不会修改当前数据。

数据保存在**当前浏览器**，不会自动上传或跨设备同步。换设备时请导出备份并恢复。备份包含学员资料，应在本地妥善保存。

保存失败会保留修改前的数据；如果已有存储损坏，页面会提示下载原始数据或恢复备份，不会自动覆盖。

## 学员名单导入

「导入学员」使用与完整备份不同的 `classbloom-roster-v1` 格式：

```json
{
  "format": "classbloom-roster-v1",
  "classes": [{
    "name": "测试班级",
    "students": [{"name": "测试学员", "account": "demo01", "grade": "7.10", "phone": ""}]
  }]
}
```

按账号匹配，保留已有积分、闪光点和记录；空的年级、手机号不覆盖已填写资料。重复导入不会重复添加。跨班级账号冲突或格式错误时，整次导入不会写入。旧班名「莲花实验班」按「莲华实验班」识别。

真实学员名单保存在仓库之外，不要提交到公开 Git 仓库。可用以下命令将名单打包成可直接打开的私人本地版：

```sh
node scripts/build-local.cjs /path/to/名单.json /path/outside/repository/课堂本地版.html
```

首次打开会导入名单，之后保留该浏览器中的积分修改。

## 验证

数据测试无需安装依赖：

```sh
node tests/data.test.cjs
```

浏览器回归测试需要本机有 Playwright 和 Chromium：

```sh
node tests/browser.cjs
```

默认 Chromium 路径为 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定。测试仅使用虚构资料，不连接外部服务。

站点：https://rongbore.github.io/student_score/

静态发布仅复制应用文件，不包含测试、备份或私人名单。本次本地修改不会自行推送或发布。
